# Гардероб скинов и плащей ASTRUM

Интерактивная 3D-примерочная скинов и официальных плащей Minecraft для проекта **ASTRUM** (`astrums.pro`), вдохновлённая гардеробом `sakeva.net/wardrobe`.

## Возможности

1. **3D Просмотр (`skinview3d`)**:
   - Полноценная 3D-модель персонажа с вращением и зумом мыши / жестами.
   - Поддержка переключения анимации бега/ходьбы и кнопка быстрого сброса угла обзора.
   - Автоматическое определение модели **Classic (Steve 4px)** vs **Slim (Alex 3px)** по альфа-каналу текстуры руки с возможностью ручного переключения.
   - Автоматическая конвертация старых скинов 64×32 (Minecraft до 1.8) в современный формат 64×64.

2. **Официальные плащи Minecraft**:
   - 13 официальных плащей Mojang (15th Anniversary, Vanilla, Cherry Blossom, Migrator, Twitch, TikTok, Copper, Menace, Home, Yearn, Common, Pancape и др.).
   - Пиксельные превью-иконки плащей, динамически вырезаемые из оригинальных текстур Mojang.
   - Мгновенная примерка плаща на 3D персонаже.

3. **Загрузка скинов**:
   - **Файл**: Drag & Drop или выбор PNG-файла на компьютере/телефоне (валидация 64×64 или 64×32).
   - **Ссылка**: Вставка прямой ссылки на скин из **Discord**, **Imgur** и любых других хостингов.

4. **Генерация команды для сервера (`/skin url`)**:
   - Интеграция с сервисом [MineSkin](https://mineskin.org/).
   - Выдаёт готовую команду для игрового чата (плагин SkinsRestorer):  
     `/skin url "https://minesk.in/..." classic` или `slim`.
   - Кнопка копирования в один клик и всплывающее уведомление (toast).

5. **«Мой гардероб» (локальное хранилище игрока в браузере)**:
   - Сохранение любимых скинов прямо в память браузера (используется `IndexedDB` с fallback на `localStorage`).
   - Для каждого скина генерируется превью лица (аватар 2D с шлемом/оверлеем), сохраняется выбранный плащ, модель и готовая команда.
   - Игрок может в любой момент нажать на сохранённый скин и надеть его обратно в 3D сцену, либо удалить ненужный.

## Развертывание Cloudflare Worker (`wardrobe/worker.js`)

Гардероб спроектирован так, что **уже работает «из коробки» без внешнего бэкенда** через прямой браузерный fallback к API MineSkin.

Однако для:
- Загрузки скинов по ссылкам Discord/Imgur без проблем со сторонним CORS или истекающими Discord CDN ссылками;
- Мгновенной генерации для скинов, которые уже кто-то загружал ранее (SHA-256 кэширование);
- Использования собственного персонального MineSkin API-ключа;

Рекомендуется развернуть `wardrobe/worker.js` в Cloudflare Workers:

### Инструкция:
1. Зайдите в панель [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create Application** → **Create Worker**.
2. Назовите воркер, например, `astrum-wardrobe-proxy`, и нажмите **Deploy**.
3. Нажмите **Edit code**, вставьте содержимое файла `wardrobe/worker.js` и нажмите **Save and Deploy**.
4. *(Опционально)* В настройках воркера (**Settings** → **Variables**):
   - `MINESKIN_API_KEY`: ваш API-ключ с [mineskin.org/apikey](https://mineskin.org/apikey) (для снятия общих лимитов).
   - `ALLOWED_ORIGIN`: `https://astrums.pro` (или `*`).
5. *(Опционально, для кэша)* В **Settings** → **Variables** → **KV Namespace Bindings** создайте KV-хранилище `SKIN_CACHE` и привяжите его к воркеру. Скины с одинаковым хэшем будут выдаваться мгновенно из Cloudflare KV без повторных обращений к MineSkin.
6. В файле `wardrobe/app.js` (или глобально в `<script>`) укажите адрес вашего воркера:
   ```javascript
   window.WARDROBE_WORKER_URL = "https://astrum-wardrobe-proxy.<ваш-поддомен>.workers.dev";
   ```
   Либо измените константу `DEFAULT_WORKER_URL` в начале `wardrobe/app.js`.
