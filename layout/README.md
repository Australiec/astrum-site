# Единые шаблоны Header и Footer сайта ASTRUM

В этой папке хранятся общие компоненты для всех страниц сайта:
- `header.html` — шапка сайта (логотип, навигация, переключатель темы, кнопка «Начать игру», мобильное меню).
- `footer.html` — подвал сайта (логотип, копирайты, ссылки на разделы и соцсети).

## Как это работает

1. Когда вы меняете `layout/header.html` или `layout/footer.html`, запустите:
   ```bash
   npm run build
   ```
   или только обновление разметки:
   ```bash
   npm run build:layout
   ```

2. В режиме разработки:
   ```bash
   npm run dev
   ```
   Скрипт автоматически следит за изменениями файлов в `layout/` и сразу же обновляет все страницы сайта на лету.

## Правила страниц

- **Главная (`index.html`)**: содержит `header` и `footer`.
- **Карта (`map/index.html`)**: содержит `header`, но **без** `footer`.
- **Вики (`wiki/`, `wiki/*/`)**: содержат `header` и `footer` с корректными относительными путями глубины страниц.
- **Страница ошибки (`404.html`)**: намеренно **не содержит** ни header, ни footer.

## Переменные в шаблонах

- `{{ROOT}}` — относительный путь к корню сайта (`./` на главной, `../` на карте, `../../` в подразделах вики).
- `{{HEADER_CLASS}}` — дополнительный класс шапки (на карте и вики подставляется ` solid` для непрозрачного фона).
- `{{NAV_ACTIVE_HOME}}`, `{{NAV_ACTIVE_MAP}}`, `{{NAV_ACTIVE_WIKI}}` — подсветка активного пункта навигации.
